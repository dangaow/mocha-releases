## 下載安裝

1. 到 [**Releases**](https://github.com/dangaow/mocha-releases/releases/latest) 下載 `Mocha-x.y.z-setup.exe`
2. 雙擊安裝，可以自己選安裝位置
3. 第一次打開會有一段可愛的引導：選語言、深色 / 淺色、背景，還能從 Chrome / Edge / Firefox 匯入書籤、密碼和瀏覽紀錄

> **跳出「Windows 已保護您的電腦」？**
> Mocha 目前還沒有數位簽章，點「**其他資訊**」→「**仍要執行**」就可以了 (｀・ω・´)ゞ

**更新**：有新版本時 Mocha 會提醒你，點「立即更新」就好。國內會自動挑比較快的鏡像下載，下載完先核對檔案，
裝好自動重新打開、分頁照樣還原；萬一新版本開不起來，會自動退回原本的版本。

系統需求：Windows 10 / 11（64 位元）

## 1.0.1 有什麼

### ☕ 工作臺：主頁是你的小桌面
Mocha 的主頁不是網頁，而是一張張可以拖動、放大、藏起來的小卡片：
待辦、筆記、番茄鐘（專注時擋掉分心網站）、剪貼簿、常用網站和軟體、遊戲庫（Steam、Epic、原神…）、音樂、下載、電腦狀態。
內建背景會慢慢動（有顯示卡時），粉藍泡泡、檸檬葡萄、莓果汽水…大家都能用。

### 🪪 個人介紹卡
挑皮膚、放頭像、選標籤、貼便利貼和照片，存成**無損 PNG**，發推特也不會被壓糊。照片只存在你的電腦上。

### 🛡️ 安全與隱私
- **防詐騙**：高仿網址（`paypa1.com`、`alipay-verify.top`…）跳出警告；偽裝成安裝檔的可疑下載先暫停
- **被撤銷的憑證擋下來**：和 Chrome 用同一份清單，私鑰外洩的憑證打不開
- **擋追蹤**：第三方 Cookie 預設封鎖、網址裡的追蹤參數自動清掉、內建廣告攔截
- **都加密存著**：密碼、Cookie、瀏覽紀錄、筆記用系統金鑰加密；密碼保存器還能再加一道主密碼
- **不收集個人資料、沒有統計**

### 💻 給寫程式的人
- 打開 JSON 自動排整齊、上色、可以收合（跟著深色 / 淺色）、程式碼字型可以自己選
- 會員還有進階小工具：指令列（`Ctrl+K`）直接算 JWT、時間戳、顏色、正則，GitHub 卡片看 PR 和 CI

### 📖 閱讀與翻譯
閱讀模式（字級、配色、朗讀）、整頁翻譯（雙語對照）、選字就能翻譯、Shift+點連結先預覽。

### 🧩 Chrome 擴充功能
從 Chrome / Edge 商店直接安裝：uBlock Origin Lite、Dark Reader、沉浸式翻譯、Bitwarden、Tampermonkey…

### ♡ 萌語
語言選單裡的「萌語」把每一句話都換成軟軟的說法，還藏了一堆彩蛋：戳戳小莫茶、在搜尋框打 `/運勢`…

### ⚡ 還有
直式 / 橫式分頁、固定分頁和分頁群組、分割畫面、分頁休眠、多視窗、Alt+Space 小搜尋框、自訂快捷鍵、
截圖、正在播放和歌詞、加密備份、36 個成就，斷網的時候還能玩接豆豆。

## 常見問題

**打開後沒有出現視窗？**
先到工作管理員結束所有 Mocha，再打開一次。還是不行的話，到「設定 → 關於 → 匯出診斷資訊」把檔案傳給我們（裡面的網址只留網域、不含個人資料）。

**防毒軟體說有問題？**
因為還沒有數位簽章，部分防毒軟體可能會誤判。請只從這個頁面的 Releases 下載。

**怎麼移除？**
Windows 設定 → 應用程式 → 找到 Mocha → 解除安裝。
